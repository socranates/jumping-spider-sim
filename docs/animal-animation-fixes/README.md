# Dog collar and cat gait fixes

The dog lowered and rotated his neck to sniff, while the collar and tag kept their standing transforms. Both now inherit the same neck transform. Regression checks measure their position and rotation relative to the neck throughout the outdoor circuit, including sniffing, turns and weather stops.

The cat's body moved across rooms, but its pose used the original windowsill prey director's clock. That clock intentionally stops when its population is inactive. Cat presentation now uses the running world prey animation clock, as the other region-independent body drawers do. The existing distant pose throttle and pause/slow-motion behavior remain. The real-client regression enters the volunteers' back room, confirms the sill clock has stopped, and observes the drawn front paw still moving.

`regressions.json` and `before-*.txt` retain the failures reproduced against the preceding source. `receipt.json` binds the fixed production sources and test/type/compile evidence: five suites, 38,060 passing checks, strict analysis and 222 compiled modules. Neither fix alters animal behavior, save schemas, collision geometry or population counts.

The restarted Studio ran a small local scene with the exact production LivingWorld and CatBody modules. `native-receipt.json` records 1,400 checked frames, attached collar/tag transforms and changing cat paw positions, without CreatorErrors. The scene was observed directly. This is isolated presentation evidence; the full-game other-room path is covered by the real-client shim test. It is not a full-game native walkthrough or an FPS result. The first private scene needed a WaitForChild fix for startup module replication; its package manifest is retained separately.
