## Reproduce

From roblox_port, run `python tests/run.py path/to/luau`, then `python tools/build.py path/to/rojo`. Open TheWindowsillTests.rbxlx in Studio, Play, and wait for both PORT_TEST_SUMMARY and PORT_CLIENT_REPORT. Run `python tools/collect_studio_report.py path/to/Studio.log ../docs/verification/roblox-silk` to collect complete matching reports. TestService.PortTestReport retains the full engine report; individual JSON rows avoid Studio log truncation.

The golden exporter reads frozen scripts/movement/tether.gd (reference c87ce00): `python tools/export_tether_golden.py path/to/godot`. Expected values are not generated by the port. Build evidence hashes source/test Luau and project JSON bytes, not documentation or Python tools.

## Limits

This is the core silk port, not a pass of Godot M03 or full contact parity. Catch framing (45-degree cap), dedicated camera collision/auto-pitch, ten-miss recovery acceptance, physical multi-touch/controller feel, large text and low-end frame-time measurement remain. One bend is supported; additional obstruction reports a snag. Pre-existing overlaps and full Godot fallback/sleep behavior are not ported. Roblox Spherecast does not detect initial overlaps (official WorldRoot reference: https://create.roblox.com/docs/reference/engine/classes/WorldRoot).

A 0.6-stud leg-reach contact acquisition at the shortest line lets the spider recover onto a real nearby attachable face; a sphere sweep rejects intervening obstacles. Edge-first lowering uses a short seating offset to clear the rim, not the full Godot edge-arc implementation. Godot gameplay, tuning, tests and SPEC remain unchanged; no new full Godot suite run was needed or claimed.
