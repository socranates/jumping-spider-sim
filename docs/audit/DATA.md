## Runtime ownership and data flow

Server/Main builds collision, decor and lighting and selects the active world before persistence validates it. Server/WorldFocus receives finite bounded positions and moves only the caller's replication focus. Server/Persistence owns SaveService and its once-per-second scheduler; it loads on join, flushes on leave/shutdown. SpiderClient owns the render callback and a 1/60 simulation accumulator; body/GUI draws follow the simulation. LookStream handles client-only looks, while collision comes from server models.

| Rest envelope, schema 1 | payload is Checkpoint below | SaveRest.check validates bounded plain values, JSON length, slot/rule agreement and Checkpoint.check; current cap 262144 chars / 120000 nodes / depth 24 |
| Checkpoint, schema 3 | schema_version, kind, game, content_revision, created_at, snapshot_tick; player(position, normal, heading, gaze_pitch, retreat_id, state); world_map(seed, revision, region, retreat, diffs, optional world); world object graph; life_rules(mode/rules); optional breakaway, wasp, cat, water | Checkpoint.capture -> local CheckpointStore and SaveClient -> server SaveRest -> restore. Checkpoint.check/decode validates first; commit changes live roots only after acceptance |
| Object graph, object-record-1 | roots(prey, sensor, memory, needs, life; optional garden), objects(c?, e entries); tagged refs/objects/vectors/special numbers | ObjectRecord.capture/decode/commit; named class/ref allowlists, 20000 object cap, sorted numbering |

Checkpoint CONTENT_REVISION is windowsill-roblox-1. Old checkpoint schemas 1/2 add missing growth/granted fields; current damaged records are not repaired that way. Legacy absent world_map and earlier map revisions use explicit location recovery; preserve-2 -> preserve-3 uses CompactMigration with validation before retiring moved route caches. This does **not** migrate a historical test-garden ecology into preserve (A04). All earlier revisions still need fixture-by-fixture coverage; do not read this map as a promise of universal compatibility.
