Eye-view picture cost (PERF-01 follow-up, T13b), Claude, 2026-10-12.
measure.gd: the same windowsill view, world frozen, 1280 x 720, 120 frames per row, three rounds each.
Software rendering (Mesa llvmpipe under xvfb, opengl3): compares shader versions with each other only, NOT laptop frame times.

Before (12 full-size blur reads per pixel, centre read everywhere):
  picture off: means 58.1 / 55.5 / 56.0 ms     picture on: means 90.2 / 85.4 / 90.1 ms   -> the picture costs about 32 ms here
Tried: 4 reads of the mipmapped picture: picture on 105.2 / 96.6 / 100.5 ms (worse here: llvmpipe makes the mipmaps on the CPU every
  frame; on a real graphics chip it may well be faster, so it is a candidate for Chet to try on the laptop, not shipped)
After (6 full-size reads on a fixed spiral, centre read only inside the sharp fields, torsion cos/sin once a frame):
  picture off: means 59.6 / 55.2 / 56.3 ms     picture on: means 79.7 / 78.1 / 79.0 ms   -> about 21-23 ms, roughly a third less

Look: stills of the same scene before and after differ by about 2 / 255 per channel on average (eye_motion_shimmer, eye_grey);
the soft surround keeps its softness, with slightly crisper doubled edges at strong contrasts.
