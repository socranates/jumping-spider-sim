Unpublished final test source `bd91ee2ec2f4db1dad296cd2be9fc1ee23f4938e` on `codex/preserve-captions`, evidence `fbcc7d9ce546a9b8`. Production code is byte-identical to the initial caption source `a36789375dd75920c0eca59ac524644b8776477f`.

The preserve's minimal HUD now honors Captions set to Normal or Large. Off hides an ongoing caption immediately. Unset/invalid settings and Reset use Off in the preserve, so a fresh play screen remains wordless. Saved Normal/Large choices still work. The legacy test garden retains its Normal default. The menu reads the same effective value as the HUD.

The minimal projection accepts only a caption produced by the sound/vibration/scene caption path; it does not admit the eye-view tutorial or routine status text. Existing fades, text sizing and priority remain. Hunger stays unlabeled. No new setting, save schema or network field was introduced. Movement, camera, hunting, feeding, physics, lighting and habitat are unchanged.

Three production modules changed: SpiderClient, SpiderHud and SettingsModel. The new regression in `minimal_hud.luau` drives the actual preserve client and settings callbacks, including a forced audible wasp, Normal/Large/Off, reset and keyboard/gamepad/touch device modes (the initial shim test used an invalid controller name; its correction has separate receipts). These are shim integration checks, not physical controller/touch or native rendering evidence.

See `docs/preserve-captions/receipt.json` for source-bound build/type/test/CI gates and `docs/preserve-captions/baseline-regression.txt` for the old-source failure.
